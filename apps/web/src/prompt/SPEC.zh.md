# prompt —— 共享的命令感知输入行为

> 中文译文，原文见 [`SPEC.md`](./SPEC.md)。英文原文是唯一权威来源，二者不一致时以原文为准。

## 职责（Responsibility）

命令感知 prompt 字段背后可复用、与生命周期无关的行为：斜杠解析与匹配、键盘／菜单交互、命令目录
归一化、竞态安全的 prompt 模板选择，以及与 Pi 兼容的模板槽位编辑。chat 与前置会话的工作区创建各自
提供自己的目录、模板读取器、几何与提交动作；本模块在提供了等价数据之后，让这些输入行为一致。

## 边界（Boundary）

- **拥有：** props 驱动的斜杠菜单与补全控制器；纯目录合并与命令插入；frontmatter 剥离／模板组装；
  占位符的解析、编辑、镜像、高亮与收尾；以及拒绝覆盖选择之后被改动草稿的模板选取控制器。
- **公开接口：** `index.ts` 是唯一的导入路径，重新导出命令补全、模板文本、模板选取、模板槽位，以及
  光标／选区恢复（`usePendingSelection`）的 API。
- **允许的依赖：** `contracts` 类型、React、`@thinkrail/locales`（UI 字符串）、
  `@thinkrail/ui/utils`（`cn`），以及 `@thinkrail/ui/button`（`TemplateSlotHint` 是一个共享
  `Button`）。
- **禁止：** 访问 store 或 transport；查找工作区／会话／项目；决定某个生命周期中存在哪些命令；发送
  prompt；导入 `chat` 或 `panels`。

## 行为（Behavior）

斜杠 token 只在草稿开头、且在其第一个空白之前才是活动的。Up/Down 在可见匹配项之间环绕；Enter/Tab
选择；Escape 关闭；由输入法拥有的按键事件在消费输入中优先。目录合并是确定性的，并让调用方更具体的
较晚来源替换同名的较早来源。

模板选择是“最后一次选取胜出”，且仅当草稿与选取时的值逐字节相同、且调用方的项目／工作区上下文未变
时才应用。选取器暴露待定状态，使提交控件在它解析期间保持禁用；草稿仍可编辑，而一次编辑或上下文切换
会让这次延后的应用失效。被选中的模板替换整个草稿。Tab 与 Shift+Tab 在占位符之间循环，Escape 结束槽位
会话，被编辑的重复组在离开槽位时镜像，提交则移除未触碰的标记。呈现助手暴露相同的提示与高亮状态，同时
把每个输入自身的布局留给其所有者。`usePendingSelection` 在 layout effect 中应用所请求的光标／选区，
与值变化在同一次提交中、绝不是延后的一帧：若有一帧落在某次后续全选与其插入之间（一次粘贴、Playwright
的 `fill`），选区会被折叠，于是插入变成追加并使草稿翻倍。
