# shell/terminalReconciliation —— 终端目录与本地 placement 的收敛

> 中文译文，原文见 [`SPEC.md`](./SPEC.md)。英文原文是唯一权威来源，二者不一致时以原文为准。

## 职责（Responsibility）

把宿主权威的终端目录与某个前端界面按工作区局部的终端引用做归约，同时保持 PTY 生命周期、frame
几何与工作区 attention 相互分离。

## 边界（Boundary）

- **拥有：** 权威目录的推进追踪；仅在目录就绪之后才修剪本地引用；标题刷新；以及当确定性初始终端
  不在该界面的工作区 view 中时，对它做被动本地播种。
- **公开接口（`index.ts`）：** 挂载的终端目录／本地 placement 归约 hook，以及意图处理所用的终端
  placement-id 助手。
- **外部依赖：** contracts 的终端类型；store 的终端目录与本地工作区 view 状态；由面板拥有的目录水合
  hook；React。
- **禁止：** 创建／附加／关闭 PTY；终端流归属；选中一个被被动恢复的终端；为迁就目录状态而改变 frame
  拓扑／几何；直接 WS 调用；面板渲染；server/shared/pi 导入；当前布局 transport；或把本地引用当作
  终端存在的证明。

处于预留待定状态的终端留在其发起界面显式 placement 意图之后，直到宿主目录确认它们。一个已确认的
确定性初始终端若不在本地工作区 view 中，会被播种到某个已有的兼容槽位而不被选中，优先底部，回退到
最近聚焦的中心组；恢复绝不隐式重塑 frame。其他目录中的终端绝不会仅因另一个前端创建了它们就获得
placement。已有的本地 placement 也绝不会仅因另一个前端在自己的 view 中移动了同一个宿主终端而移动。

目录移除会在就绪之后修剪指向该终端的每一个本地引用，并归约 attention。显式的宿主终端关闭仍是唯一
的 PTY 生命周期动作；本地 frame 移动与预设应用保留目录身份。
