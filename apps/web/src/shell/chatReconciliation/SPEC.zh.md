# shell/chatReconciliation —— 本地 chat placement 与宿主缓存的收敛

> 中文译文，原文见 [`SPEC.md`](./SPEC.md)。英文原文是唯一权威来源，二者不一致时以原文为准。

## 职责（Responsibility）

把宿主拥有的 chat／会话存在性与转录，与本前端界面按工作区局部的 placement、渲染缓存和历史做收敛 ——
且不把缓存状态变成 placement 权威。

## 边界（Boundary）

- **拥有：** 对本地已放置 chat 的按代次限定的水合；带有限被动自动打开能力的权威会话列表归约；
  精确 chat 路由目标的校验与第一优先级本地 placement／焦点；目录／转录失败的汇报与可重试的历史回退；
  缺失／已立墓碑会话的修剪；chat 位置／深链接的编排；以及安装前的过期读取／本地 placement 复查。
- **公开接口（`index.ts`）：** 挂载的墓碑、目录／缓存与 chat 位置归约 hook，以及意图处理和重试 UI 所需
  的本地已放置 chat 水合／当前目标操作。
- **外部依赖：** contracts 的 chat／会话类型；chat 转录水合；store 的会话／缓存／navigation API；
  transport 的会话读取；shell 中立的 `lib`；React。
- **禁止：** 宿主会话生命周期、终端归约、frame 几何／拓扑、通用 placement 策略、功能面板渲染、
  server/shared/pi 导入、当前布局 transport，或仅因领域水合到达就选中某个标签。

每条异步路径在安装状态之前都会校验连接代次、工作区／会话墓碑、当前请求身份，以及仍然存活的语义
本地 placement。一个精确 chat 路由目标在未解析期间拥有自己的会话水合，从而避免重复读取。只有成功的
权威性缺失才会消费一个未解析的目标；目录／转录失败会保留它以便重连。一旦它的本地 placement、
工作区 attention 与运行时收敛，该目标即被清除，URL 同步恢复。

本地持久化的 chat 引用在工作区激活时水合。在权威会话列表读取时，**仅当同一遍中没有正在处理的精确
chat 路由目标**时，最多 `AUTO_OPEN_CHAT_LIMIT`（4）个仍未放置且存活或带有未完成 todo 的会话会被
被动打开，最新者优先；如果工作区打开时没有任何已放置项且没有任何会话符合条件，则单个最近的会话作为
回退打开，这样在有 chat 历史时工作区永远不会落空。分类与回退都从该次读取中的每个未放置会话取材，
无论其运行时是否已在本地已知（例如一个刚被 `closeChatToHistory` 取消放置的会话，它保持运行时存活
正是为了让这件事发生）—— 已知会话会直接从缓存重新打开（已有的 `tabsByWorkspace` 条目，或用
`closedChatsByWorkspace`／摘要为其取标题的合成条目），而不是重新拉取；只有尚无本地运行时的会话才走
拉取并水合的路径。正在解析路由目标的那一遍会完全跳过被动自动打开，而不是仅仅排除目标自身的会话 ——
否则与之同时打开的一个无关活动 chat 可能从该界面被要求落到的链接底下夺走组的选中项。被动自动打开
**每个 (workspaceId, connectionGeneration) 至多尝试一次**，以一个按工作区 id 为 key 的模块级 set 锁存，
并在连接代次推进时清除 —— 它不是 per-mount ref，因为无论承载组件是原地重定向（现在就是这样）还是
重新挂载，该锁存都必须能挺过界面离开并回到某个工作区的过程。这个锁存防住了两件事：会话列表 effect
会在每次 `commit` 身份变化时重新触发（只要文档变化其调用方就会重建 `commit`，例如就在同一个 effect
放置了一个标签之后），因此没有它的话，一个在两次这种重新触发之间被解析并清除的路由目标，会让之后
同一次挂载中一个现已无目标的遍被动打开一个无关的活动会话，把目标顶掉；以及从一个工作区切走再切回
绝不能被看成一次全新的到达，否则另一个前端在本前端身处别处时启动的 chat 会在本地被打开，而不是像
任何其他“尝试之后才到达”的会话那样进入历史。其他一切 —— 包括限额已用完之后的存活／未完成会话，或
在尝试已用完之后才到达的会话 —— 只进入历史。一次失败的已放置转录读取会被汇报，并让该会话在历史中
保持可重试；一次失败的目录会被汇报，而不是呈现无从解释的空白。被取消、已断开或已被移除工作区的遍
保持静默。每个被接受的本地转换都是同步的，因此 chat 位置工作不需要宿主布局写入屏障；仅凭请求时的
navigation 戳就能防止一次过期跳转让较新的关闭或选择被撤销。
