# body.md —— 维护 PR 标题或正文

> 中文译文，原文见 [`body.md`](./body.md)。英文原文是唯一权威来源，二者不一致时以原文为准。

入口：一个已打开的 PR，外加一处被请求的标题/正文改动。只在编辑正文期间保存
`.thinkrail/context/pr-body.md`。默认完成模式是快照模式；仅当主干明确的远端完成规则选中它时，
才保留等待模式。

1. 取当前标题与正文（`gh pr view <n> --json title,body`），并在存在时读取仓库的
   `.github/PULL_REQUEST_TEMPLATE.md`。保留既有的章节、issue 链接、检查清单条目以及无关内容；
   只施加被请求的那处改动。
2. 对正文编辑，把完整的候选内容写入 `.thinkrail/context/pr-body.md`。在 `gh pr edit` 之前立即
   再次取当前正文；如果它变了，就把被请求的改动合并进那份新鲜正文，而不是覆盖并发的编辑。
   使用 `gh pr edit <n> --body-file ...`，绝不用内联正文。对标题编辑，也要立即重新取当前标题；
   如果它变了，就在 `gh pr edit <n> --title ...` 之前，把被请求的那处改动重新应用到那份新鲜标题上。
3. 取一次结果中的标题/正文，验证被请求的改动确已落地，然后删除正文文件。
