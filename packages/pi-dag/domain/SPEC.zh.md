# DAG 契约与纯域规则

> 中文译文，原文见 [`SPEC.md`](./SPEC.md)。英文原文是唯一权威来源，二者不一致时以原文为准。

## 职责（Responsibility）

拥有带类型的图/命令 schema、公开 DTO、持久化的域证据，以及纯的图校验、就绪、陈旧传播与授权。
图/命令类型与持久记录类型从其校验 schema 推断；公开的读取投影保持独立。持久记录区分版本、尝试、
激活、提案与门禁。解码要求自洽的产物身份，并解析每个证据目标、worker 调用回执与输出选择；
处置必须携带其含义所需的决策/文件，而每个门禁决策的行为者都针对其存储的策略被重新授权。
Delegation 的诞生元数据在进入状态之前，按同一份存储的诞生 schema 校验；
更宽泛的 delegation 契约不被复制。

## 边界（Boundary）

barrel 向同包兄弟暴露契约、schema、校验/错误辅助函数与纯的图/状态操作。允许的外部依赖是 typebox
与仅类型导入的公开 pi/delegation 类型。禁止：文件系统、provider/会话实例化、传输层、运行时或持久化导入。
父规格拥有同级依赖边。公开的包导出选择客户端契约；私有的持久状态不会自动经包 barrel 发布。

## 不变量（Invariants）

在提交之前校验整张图：安全的唯一 id、无环连接、已声明且兼容的端口且恰好一个生产者、
恰好一个显式的 fork 基点、且没有跳过的 fork 源。必需的输入需要生产者。
就绪消费已接受、当前、已授权的证据，而不只是终态。受影响的子孙包括等待/暂停中的工作。
授权是受信任的绑定来源；`human-or-controller` 是穷尽的，因此所有者回调不满足任何一种调用方类型，
也不决定任何门禁。取消不决定门禁：未解决的当前尝试门禁仍保护 skip 与依赖编辑，
即使它们的执行已被取消。显式重试取代那次尝试，但保留该节点的释放/输入策略。
省略的 `inputAuthority` 意为仅限人类，即使尚未出现第一个输入门禁：削弱该策略或移除该节点都需要人类来源，
正如一条显式的 human-only 策略那样。Revision 永不擦除先前的证据。
编辑准备一次性地算出已校验的图、受影响的节点与所需的权限；只有当获取到的状态仍具有所准备的版本、
且匹配调用方的期望版本时，运行时才复用那个结果。这包括盖在重放回执上的权限：
一次所有权的移交不能复用更旧快照的授权。
挂起的延续只存储其载荷。解码仍接受已废弃的可选 `sourceActivation` 字段，
使先前保存的延续保持可读；它没有控制权。
